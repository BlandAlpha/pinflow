## Todo Tracker 桌面应用（从零到可用 MVP，已交付）

- 完成 Electron 33 + React 18 + TS + electron-vite + better-sqlite3 + Zustand + Tailwind/shadcn 风格组件的本地 Todo 应用。
- 功能：全局 Ctrl+Shift+Space 快速捕获小窗、收件箱/今天/四象限/全部四个视图、拖拽改象限、透明优先级评分（shared/priority.ts，13 个单测通过）、详情面板+步骤子任务、键盘全操作、托盘常驻、开机自启、归档撤销。
- 关键经验：
  1. 本机无 MSVC，better-sqlite3 不能本地编译 —— 用 `scripts/fetch-native.mjs` 从 GitHub/npmmirror 下载官方 electron-v130 预编译二进制放到 `node_modules/better-sqlite3/build/Release/`；electron-builder 需 `npmRebuild: false`。
  2. 本沙箱环境：前台启动 GUI 程序会被 SIGTERM；`ELECTRON_RUN_AS_NODE` 在提权命令中会泄漏进子进程导致 `electron.app undefined`（用 `env -u ELECTRON_RUN_AS_NODE`）；**同一进程创建第二个 BrowserWindow 会被环境阻塞**（原生 Electron 复现，与业务代码无关）——快速捕获窗口需在真实桌面手动验证。
  3. electron-builder 打包 winCodeSign 解压需要符号链接特权（失败）；解法：`win.signAndEditExecutable: false` + npmmirror 镜像变量，免安装版打包成功。
  4. npm 部分安装损坏后（*.DELETE.* 文件），删除单个包目录重装即可修复；大目录删除受 safe-delete 守卫限制（>50 文件需确认）。
- 冒烟测试钩子：`npm run smoke`（electron . --smoke）自动造数据、切换视图截图到 `.smoke/`、校验全局快捷键与跨重启持久化。
- git：6 个中文 commit（脚手架/主进程/渲染层/文档等分层提交）。
- 产物：`release2/win-unpacked/TodoTracker.exe`（免安装版）；旧 `release/` 目录有被锁文件无法删除，遗留 223MB 待用户手动清理。

## 第二轮：UI/UX 重构（从"数据库工具"到"安静的个人工作助手"）

- 交互模型改为 CAPTURE FIRST → 系统自动组织 → 用户只在需要时纠正：
  - 四象限成为唯一面向用户的分类，importance/urgency 由象限自动推导，界面不再暴露独立控件（仅收在详情"更多"）。
  - Todo 新增 `classified` / `order`；未分类任务只出现在收件箱，一旦设象限/截止/置顶/标签即移出。
  - Matrix 改为真 2×2 看板（四象限同屏 + 未分类暂存区），HTML5 拖拽跨象限改分类、象限内插入重排，即时持久化无弹窗。
  - Today 按评分阈值 45/28 分 NOW/NEXT/LATER 三档；Inbox 做成分诊台（卡片内联改名/改象限/改截止/展开步骤）；All 工具化更密集。
  - DetailPanel 渐进披露：标题 + 紧凑属性行 + 步骤 + 备注，高级信息收"更多"，归档/删除进溢出菜单。
- 主题：Light/Dark/System（默认 system）持久化到 `prefs.json`；全部颜色改语义 CSS 变量；preload 首帧 `sendSync` 取主题快照避免闪烁；主进程 `nativeTheme.themeSource` + 广播。
- 新增 shadcn 原语 popover / dropdown-menu / calendar / select；统一 TaskCard（list/board 两形态）。
- 验证：`tsc --noEmit` 通过、`vitest` 23 个用例通过（新增 tests/model.test.ts 10 个）、`electron-builder --dir` 打包成功（release-v2，旧 release/win-unpacked/app.asar 被占用，改用新输出目录）。
- 新增工具：`scripts/png-brightness.mjs` 解析 PNG 平均亮度/内容占比，用于在无法看图的环境判断浅色/深色与是否空白。
- 冒烟新参数：`--smoke-light` / `--smoke-dark` / `--smoke-size=WxH` / `--smoke-tag=` / `--smoke-views=`；注意强制主题必须在 `initPrefs` 之后调用，否则 prefsFile 为空写不进去。
- 分辨率验证（DPR 1.25）：1280×720→1604×900、1440×900→1804×1125、1920×1080→2404×1350，均正常渲染。
- git：本轮 7 个中文 commit（模型/主题/卡片/视图/测试/依赖/文档）。
