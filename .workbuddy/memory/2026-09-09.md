# 2026-09-09

## Todo Tracker 桌面应用（从零到可用 MVP，已交付）

- 完成 Electron 33 + React 18 + TS + electron-vite + better-sqlite3 + Zustand + Tailwind/shadcn 风格组件的本地 Todo 应用。
- 功能：全局 Ctrl+Shift+Space 快速捕获小窗、收件箱/今天/四象限/全部四个视图、拖拽改象限、透明优先级评分（shared/priority.ts，13 个单测通过）、详情面板+步骤子任务、键盘全操作、托盘常驻、开机自启、归档撤销。
- 关键经验：
  1. 本机无 MSVC，better-sqlite3 不能本地编译 —— 用 `scripts/fetch-native.mjs` 从 GitHub/npmmirror 下载官方 electron-v130 预编译二进制放到 `node_modules/better-sqlite3/build/Release/`；electron-builder 需 `npmRebuild: false`。
  2. 本沙箱环境：前台启动 GUI 程序会被 SIGTERM；`ELECTRON_RUN_AS_NODE` 在提权命令中会泄漏进子进程导致 `electron.app undefined`（用 `env -u ELECTRON_RUN_AS_NODE`）；**同一进程创建第二个 BrowserWindow 会被环境阻塞**（原生 Electron 复现，与业务代码无关）——快速捕获窗口需在真实桌面手动验证。
  3. electron-builder 打包 winCodeSign 解压需要符号链接特权（失败）；解法：`win.signAndEditExecutable: false` + npmmirror 镜像变量，免安装版打包成功。
  4. npm 部分安装损坏后（*.DELETE.* 文件），删除单个包目录重装即可修复；大目录删除受 safe-delete 守卫限制（>50 文件需确认）。
- 冒烟测试钩子：`npm run smoke`（electron . --smoke）自动造数据、切换视图截图到 `.smoke/`、校验全局快捷键与跨重启持久化。
